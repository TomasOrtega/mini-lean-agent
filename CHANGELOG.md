## [0.1.0] - 2026-08-26

### Added

- minimal linear native-tool-calling agent loop
- controlled `bash` and `lean` toolsets
- stateless shell execution with time and output limits
- local Lean and optional Kimina checking backends
- reserved `mini-lean-submit` bash command that rejects compiler errors and sorry warnings
- JSON trajectories, trajectory inspection, and JSONL batch evaluation
- installable `mini-lean` and `mini-lean-agent` CLIs
- documentation, Python and real-Lean CI, PyPI trusted-publishing workflow, and test suite
